So why build anything?

Because the original study had three problems that no amount of writing could fix.

ProblemWhat the build does
A failed attempt left no record at all — it printed “Not applied” and wrote nothing, so 8 of 24 cells simply vanishedEvery cell is enumerated before anything runs, and must end in a recorded outcome — one of eight, never silence
Conditions lived in 30 separate scripts with no entry point, so nobody could state what had been runOne config file, one command, a checksum over the config that changes if any setting does
The headline numbers were typed by hand into tables and figures, so nothing checked themThey regenerate from the raw logs, and the regenerated table is compared byte-for-byte with yours

The whole thing runs with no API key, no network and no Docker.

That was a deliberate constraint, not a limitation we worked around. It means anyone can verify the results on any laptop — which is the difference between a claim and a result.
